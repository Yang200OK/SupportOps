# 回答开发任务与独立初稿标签

任务不含期望输出，标签单独文件并哈希绑定。12 dev / 4 holdout，同来源家族跨版本保持同一分区；holdout 未运行。所有资料来自 RelayDesk 公开自建配置 / 产品 / 排查手册，标签为 source_rule_draft，human_reviewed=false。

不同数据集不能直接当成同任务消融。词句规则覆盖是透明代理指标，不是完整语义准确率或人工金标准。回答 / 检索 holdout 不进入本轮模型上下文，后续冻结和人工复核按项目计划进行。
