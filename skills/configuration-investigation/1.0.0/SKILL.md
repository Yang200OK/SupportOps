# 配置与版本排查

适用 RelayDesk 1.0 / 1.1 / 2.0，在线异常或明确登记的启动失败。症状词只用于选择方法，不能证明原因。

1. 检索本次版本的配置规则，分别核对实际键名、单位、配置来源与版本。不能从文档默认值推出现场实际值。
2. startup 读取 read_startup_diagnostic；它记录已经发生的启动校验与退出码，没有在线服务，不安排在线状态工具。
3. online 读取 read_runtime_state 和 read_current_observations。只从本次记录判定发生了什么。
4. invalid_keys 只能说明哪些键被拒绝；没有值或类型的观测，不能推成“值超范围”。缺失事件不能反驳假设。
5. 引用同版本原文与本次证据；条件不足时保持未决，说明需要补充的配置与复测。

此方法是自建演示资料的人工编写流程，未完成人工语义审定或成对效果评测。它不授予工具权限，不批准动作，也不是本次原因证据。控制动作只沿用应用的独立人工批准入口。
